# Library Management System

A Java-based Library Management System developed to manage books, library members, book issuing, book returning, due dates, and fines.

## 📌 About the Project

The Library Management System is a console-based Java application that helps manage basic library operations.

The application allows the librarian to add and search books, manage members, issue and return books, track due dates, and calculate fines.

This project was developed to practice Java Object-Oriented Programming, Collections, File Handling, and Date/Time API.

## 🚀 Features

- Add books
- Search books
- Display available books
- Add library members
- Manage members
- Issue books
- Return books
- Track due dates
- Calculate fines
- Store and retrieve data using file handling
- Search books by different details
- Library statistics
